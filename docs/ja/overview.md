# 概要

Skoposは、アラートの受信から復旧の確認まで、AIがインフラ障害を自律的に解決するプラットフォームです。
障害の調査と対処を担い、24時間365日のNOC運用における人間の負荷を軽減します。

AIは、観測した状態と実行結果から次の対処を選びます。
Skoposは許可された変更を実行し、対象システムが復旧したか確認します。
設定した権限と制限の範囲で対応を完了できない場合は、収集した証拠を添えて運用者に引き継ぎます。

## 環境との接続

```text
監視システム ── アラート ──> Skopos <── リクエスト / 結果 ──> AIサービス
                              │
             ┌────────────────┴────────────────┐
             │                                 │
        状態の観測 / 変更                   認証付きAPI
             │                                 │
             ▼                                 ▼
         管理対象                          WebとCLI
                                             運用者
```

監視システム、AIサービス、管理するインフラをSkoposへ接続します。
SSH、HTTP API、NETCONF、RESTCONF、Redfish、IPMIなど、管理対象に合ったアクセス方法を選択してください。
必要に応じて、１つの対象に複数のアクセス方法を追加します。

## 運用者が設定・確認すること

- **障害対応:** 調査、対処、復旧確認を１つのケースで進める。
- **権限:** 観測のみ、人間の承認、AIによるレビュー、承認なしでの変更から選ぶ。
- **制限:** 対応時間、操作数、関連対象数、AI使用量の上限を設定する。
- **監査:** アラートを待たず、調査を定期実行する。
- **証拠:** 観測、判断、変更、復旧結果を確認する。

WebとCLIのどちらからも、Skoposを設定・操作できます。
